# STUDENTI POBEDILI – Linux Theme

**Bordo i svetla desktop tema inspirisana pokretom Studenti Pobedili.**

Nezvanična fan-made personalizacija za Linux desktop okruženja, sa 4K pozadinama, prilagođenim ikonama i bojama.

[GitHub Repository](https://github.com/urosg3/studenti_pobedili_Unity)

---

## O projektu

Studenti Pobedili je desktop tema koja donosi vizuelni identitet pokreta na Linux računar.

Tema sadrži dve vizuelne varijante:

- **Bordo** – tamna varijanta sa bordo pozadinama.
- **Svetla** – svetla varijanta sa svetlim pozadinama.

## Funkcionalnosti

### 4K pozadine

Paket sadrži osam desktop pozadina u 4K rezoluciji:

- Pobeda Cinematic
- Pobeda Minimal Light
- Pobeda Desktop
- Pobeda Bordo
- Univerzitetska pobeda
- Desktop bez teksta
- Noćna pobeda
- Svetla pobeda

### Tema ikonica

- Prilagođene ikonice za foldere.
- Home, Desktop, Downloads i Documents.
- Diskovi i prenosivi uređaji.
- Mrežne lokacije.
- Korpa za otpatke.
- Podrška za različite veličine ikonica.

Posebna prilagodba za Ubuntu Unity:

- Radiance GTK tema za svetlu varijantu, ako je instalirana.

## Instalacija

Preuzmite repository:

```bash
git clone https://github.com/urosg3/studenti_pobedili_Unity.git
```

Uđite u direktorijum:

```bash
cd studenti_pobedili_Unity
```

Pokrenite instalaciju:

```bash
chmod +x install.sh
./install.sh
```

Izaberite željenu varijantu iz instalacionog menija.

**Važno:** Instalaciju pokrenite bez `sudo`. Podešavanja se primenjuju samo na trenutnog korisnika.

## Komande

Direktno pokretanje pojedinačnih opcija:

```bash
./install.sh --bordo
```

Bordo varijanta.

```bash
./install.sh --svetla
```

Svetla varijanta.

```bash
./install.sh --ikonice
```

Instalacija samo teme ikonica.

```bash
./install.sh --deinstaliraj
```

Deinstalacija i vraćanje prethodnih podešavanja.

## Bezbednost i privatnost

- Nije potrebno pokretanje sa administratorskim privilegijama.
- Ne zahteva dodatne pakete niti internet tokom instalacije.
